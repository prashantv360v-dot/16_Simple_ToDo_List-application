# 📝 Responsive Todo List

A fully responsive **Todo List Web Application** built using **HTML, CSS, and JavaScript**. It helps users manage daily tasks with a clean interface and useful features like adding tasks, marking them as completed, deleting tasks, and more.

## 🚀 Live Features

- ➕ Add new tasks instantly
- ✅ Mark tasks as completed using a checkbox
- ❌ Delete tasks individually
- 📱 Fully responsive design (Mobile, Tablet & Desktop)
- 🎨 Clean and modern user interface
- ⚡ Fast and lightweight application
- 🔄 Real-time task updates without page refresh
- 📋 Easy task management experience

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## ⚙️ How to Run

1. Clone the repository.

```bash
git clone https://github.com/prashantv360v-dot/16_Simple_ToDo_List-application
```

2. Open the project folder.

```bash
cd 16_Simple_ToDo_list-application
```

3. Open `index.html` in your browser.

No installation or additional packages are required.
